## 四、复核清单

**做第 20、21、22 项之前，先备份当前库**：复制
`%LOCALAPPDATA%\quiz-master2\quiz-master2.db` 到桌面。
第 20 项要先备份他的真实数据库再测，测完按收尾拷回。

### 设置页 key

1. **设置页 BigModel key 入口**：设置 → “数据”组 → 最后一项
   （缓存清理行之后），看到 “BigModel key” 行与说明文案
   “只存在本机安全存储，不进题库、不进备份”。
   未填过 key 时状态行显示“未设置”；输入框是密码式（输入的字符显示为圆点，
   不显示明文）。
2. **保存 key**：粘贴 BigModel key 点“保存”，状态行变“已设置”，
   输入框被清空（key 不滞留在框里）；界面任何地方都看不到 key 明文。
   保存后排队的识别任务应立即开始，不用等（worker 被唤醒）。
3. **清除 key**：点“清除”，状态行回到“未设置”。保存空输入框也视为清除。

### 导入自动识别

4. **有 key：导入自动识别端到端**：填好 key 后，导一页试卷（数学题最佳，
   含公式与 A–D 选项），确认分框后稍等（单题约 1–2 秒），
   进整理页：该题下方出现识别出的题干（公式已渲染，不是 LaTeX 源码），
   状态为“识别完成”，切分显示“自动切分”（选择题）或“未切分”（非选择题）。
   详情页打开同一题也能看到题干。
5. **无 key：只排队不报错**：清除 key 后再导一页、确认分框，
   整理页该题状态显示“等待设置 API Key”（绝不显示“识别中”），
   题目本身的保存、查看、整理、复习一切正常；填回 key 后排队的任务
   自动开始识别，不用重新导入。
6. **失败与重试状态显示**：识别失败的题（如断网时导入），状态显示
   “识别失败”，整理页/详情页点“重新识别”（失败时按钮文案为“重试”），
   任务重新排队；可重试的失败（超时、429、5xx、断网）会自动退避重试
   （30 秒 → 60 秒 → 120 秒，最多 4 次请求），重试期间状态显示
   “稍后自动重试”；key 无效（401/403）时不重试，状态显示
   “等待设置 API Key”。
7. **原图永远是最终依据**：任何题干渲染失败、识别失败、没 key 时，
   题目图（切片原图）始终正常显示；公式渲染失败时该公式处显示原图，
   其余段落正常显示，界面上看不到 LaTeX 源码、看不到报错文本。

### 整理页纠错入口

8. **纠错入口位置**：整理页每道题的“修框切片”折叠区**下方**，
   有题干区：标题 + 状态 chip + 只读渲染的题干 + [编辑题干][重新识别]。
   点“编辑题干”在切片下方原地展开，不跳页面。
9. **编辑题干**：普通文字段直接改；公式块显示渲染好的公式，
   可 [恢复为原图]（保存后该公式以原图显示）或 [删除]；
   保存后状态变“已手动修改”，切分显示“人工调整”，
   之后再来的自动识别结果只作候选、不直接覆盖人工改过的内容。
10. **候选预览**：人工改过的题再跑一次识别（点“重新识别”会先弹确认框，
    说明“原内容会保留，等你预览确认后才替换”），新结果回来后出现
    “有新的识别结果”横幅；点开是当前题干与候选题干并排预览，
    [用新结果替换] / [忽略]，先预览、再确认，绝不直接替换。
11. **编辑中不丢草稿**：正在编辑题干时，后台识别结果回来只多一条
    “有新的识别结果”横幅，正在改的草稿原封不动；
    关掉编辑器后状态才刷新。

### 详情页纠错入口与重框

12. **详情页纠错入口**：详情页题目图下方有同一套题干区
    （与整理页同一个编辑器）：[编辑题干][重新识别]、状态 chip、
    候选横幅、公式恢复为原图，行为与整理页一致。
    详情页改题干后保存，整理页/错题本看到的是同一份改后题干。
13. **重框自动重识别**：详情页对一道已有识别结果的题点“重新框选”，
    改框确认后，旧识别结果作废、新切片自动进入识别队列
    （不用手动点重新识别）；新结果回来后题干随之更新；
    人工改过的题干仍走候选保护（只出横幅、不直接覆盖）。

### 公式渲染目视（真机字形，Linux 测试只能证明不抛错）

14. **\text{} 里中文**：找一道题干含 `\text{当 }` / `\text{已知 }` 的题
    （如 cases 题），中文正常显示，不缺字、不乱码。
15. **圈号 ①②③④**：政治卷里 `\textcircled{1}` 之类的圈号显示为
    ①②③④（不是 LaTeX 源码、不是方框）。
16. **分数 / 根号 / 上下标**：数学题的分数（如 $\frac{3}{5}$ 的分数线）、
    根号、上下标（$x^2$、$x_1$）字形完整，无缺损、无错位。
17. **长公式滚动**：找一道长公式题，公式超出卡片宽度时可横向滚动查看，
    不溢出、不截断、不报错。
18. **深色主题**：切到深色主题，公式颜色跟随主题（深底浅字），
    依然清晰可读；再切回浅色也正常。
19. **破折号已知弱点（不用修，确认兜底在）**：GLM 已知会把破折号读成“一”
    （如“中国—东盟”读成“中国一东盟”），看到时用详情页纠错入口改掉即可；
    这是已知问题，不算复核失败，记下来就行。

22. **v3→v4 迁移不丢数据**：如果你是从 v3 的库升上来的，确认题目、
    文件夹、标签、复习记录、最近查看历史都在，一道没少；
    新装空库直接就是 v4，也正常。
