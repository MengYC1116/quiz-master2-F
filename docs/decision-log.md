## D-14 · 2026-11-12 · 整理工作台 · 已确认的题重进页面后又回到待整理队列（已修）

- 问题：点“确认整理，去下一道”后，界面上队列 4→3，但离开页面再回来，刚确认的题又回到待整理队列（会无限重复整理）。
- 原因：队列口径是 `reviewCount == 0`，而确认时 `reviewCount` 保持 0 不变（首次复习只改 `nextReview` 为明天），所以确认过的题仍满足“待整理”条件。确认本身是落库了的（查库可证 `next_review` 已改成明天），不是保存失败。
- 按什么想法修：给 questions 表加 `is_organized`（数据库版本 1→2，`onUpgrade` 迁移；旧库回填：`review_count > 0` 的题置 1，其余 0）；队列改为 `!isOrganized && !isArchived`；确认时 `isOrganized: true`；`_buildUpdatedQuestion` 透传该标记，避免切换题目自动保存时把它写回 false；演示数据里已复习过的 5 道题种子值 `isOrganized: true`。
- 验证：新库确认材料分析（q-pol-3）后离页再回，待整理 4→3，该题不再出现；查库 `is_organized=1, next_review=明天`。旧 v1 库升级后，已确认过的题因当初没存标记、仍会回来一次，重新确认一次即清除——这是旧库数据本身的局限，无法自动区分。
- 需要用户确认：无（bug 修复，口径与定稿一致：确认即离开待整理队列）。

## D-15 · 2026-11-12 · 全局 · 深色模式下左导航看不清（已修）

- 需要用户确认：无（bug 修复）。
