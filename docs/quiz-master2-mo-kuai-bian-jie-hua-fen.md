# quiz-master2 模块边界划分
每个页面一个独立模块 · 8 个页面 / 9 条路由
已确认的 4 页写详细边界；未确认的 4 页先划边界、列待确认点，确认一页补一页，不动其他模块。

## 一、总原则：一个页面一个模块，只靠 ID 联系
quiz-master2 按页面拆成独立模块。每个模块只管自己那一页的界面、状态和交互，模块之间不直接读取对方的页面状态，也不互相调用对方的内部代码。模块之间只通过两样东西联系：一是题目 ID、学科 ID 这类标识，二是全局共享的数据层（见第二节）。
这样拆分的目的只有一个：未来增加模块、减少模块、修改单个模块时，改动范围锁在一个模块之内，其他模块不用动。本次错题本由普通列表大改为书架式页面，就是按这个原则落地的先例。
页面即模块：一个页面对应一个模块，一条路由对应一个入口；学科管理与设置同属一个模块、占两条路由。
只传 ID：页面之间跳转只带题目 ID、学科 ID 或一组题目 ID，不把上一页的状态、筛选条件对象整包传给下一页；下一页凭 ID 自己去数据层取数。
数据只有一份：一道题在数据层只存一份，可以同时挂在多个文件夹下；任何模块都不在自己页面里复制一份题目数据长期保存。
界面状态不出门：筛选条件、滚动位置、展开收起、批量勾选这类状态只活在本模块内，离开页面即可丢弃，不写进其他模块。

## 二、全局共享层：不属于任何单个页面模块
以下四样东西全应用共用，单独放在共享层，由所有模块调用。任何页面模块都不得自己再造一份，否则增减模块时就会牵一发动全身。
路由表：9 条路由的统一登记处。加模块在这里加一行，减模块在这里删一行。
左侧导航：全应用共用的外壳，可折叠为仅图标。导航角标的数据口径归共享层展示、由对应模块供数：收集角标为待修框数加待整理数，整理角标为待整理数，错题本不显示角标。
数据层：题目、学科、文件夹、标签、试卷、知识点树、错误类型、复习状态与下次复习时间的唯一存放处。页面模块只能通过数据层读写，不能跨模块直接取对方的数据。
主题与视觉变量：亮色 / 深色两套主题（默认跟随系统、回退亮色）、学科色（数学蓝、英语绿、政治红）、圆角与字号等全局变量，以及各页空状态共用的小伙伴形象，都归共享层，页面模块只引用不定义。

## 四、已确认模块（详细边界）

### 4.1 首页 /home
管什么
继续上次：显示最近一次未完成的任务并一键回到原进度，对象可以是复习、整理或收集；三者同时存在时优先级为复习高于整理、整理高于收集。
今日到期焦点大卡片（C 焦点大卡片版式）：汇总今日到期题数，逾期题一并计入并标注逾期天数；整张卡片点击进入复习，卡片内的继续按钮进整理工作台，两者互不误触。
快速收集：只提供文件导入一个入口，在此只负责发起并跳往收集中心。手机照片传输按钮已删除，手机照片传过来本质上就是选文件，不单列为一个入口。
各学科待复习概览：按数学、英语、政治的固定顺序，每科只显示三个数字——今日到期、复习中、已掌握，不显示总题数。
空状态：今日没有到期复习时，显示小伙伴形象与相应提示文案；没有可继续的任务时只显示今日到期卡片。
不管什么
不做顶部全局搜索、不设底部状态栏、不显示待整理提醒、不显示最近打开列表、不显示今日进度与明日预告、不做首次使用引导、不设键盘快捷键。
不直接编辑、复习或整理任何题目，本页只汇总与跳转，实际操作一律去对应模块完成。
不新增手动录入题目入口，收集只有文件导入一条路。
进出靠什么
进：应用启动后的默认页，或从左侧导航进入，不需要任何参数。
出：点焦点卡片去复习（不带参数，复习模块凭数据层取今日到期题）；点继续按钮去整理工作台；点快速收集去收集中心；点某学科行去错题本并带上学科 ID，直接打开对应那一本。
和其他模块的联系
只读数据层：今日到期数、各科三项计数、最近一次未完成任务，都向数据层查询，本页不保存题目数据。
与错题本唯一的特殊约定：首页学科行入口带学科 ID 直达打开状态，这是错题本对外的两个入口形态之一（另一个是无参数进书架）。

### 4.2 收集中心 /collect
管什么
文件导入：只接受 PDF、JPG、PNG；PDF 上限 50MB、图片上限 20MB，超限只提示不硬性拦截；多文件排队逐个导入并显示百分比进度，导入可取消，导入队列在应用重启后保留。
导入时选学科：导入框上方一条紧凑的单行学科下拉，默认上次所选学科；学科在此定下，后面修框与整理环节都不能再改。
导入校验：重复导入时提示已导入过、仍可再次导入；加密 PDF 提示先解锁，解锁后正常导入；损坏文件显示具体失败原因，其任务删除不需要二次确认。
任务列表：按时间倒序，可按状态筛选；任务超过 3 条时列表成为可滚动容器，不超过 3 条时为普通列表；已整理完成的任务归档，不再出现在列表中；取消导入中途的任务停留在修框中状态。
修框编辑器：以较大的覆盖层打开（覆盖 / 替代上传区，不在任务列表下方展开页面），全程鼠标操作——拖动移动、拖角缩放与旋转、滚轮缩放、拖动平移，并有整页旋转按钮（每次 90 度，框随页面一起转）和恢复自动框按钮。
两层框：第一层整题框、第二层题干 / 选项 / 配图框，两层都可新增与删除；新增框先画框、再在框旁小菜单选类型，默认整题框；双击整题框进入内框模式，Esc 或点空白处退出。
多页与多题：多页 PDF 在编辑器底部有带页码的缩略图条，切换页面时各页框编辑保留；一页多题时一次框完，确认后拆成多个任务，原任务不保留。
确认校验：框相互重叠时在确认时提示；已有框被钳制在页面范围内、拖到边缘即停，新画的框同样不得超出页面；一题未检测到框时提示用户手动拖框。
不管什么
不做文字识别（OCR）：本模块只负责把整题框与二层框切成图片，不识别文字内容。
不做框外检测：不提示框画偏、文字被切、置信度或框重叠检测，重叠只在确认时作一般提示，框得对不对由用户自己看。
导入失败不提供重试按钮，用户自行检查文件后重新导入。
任务不可改名，任务名固定为文件名加页码加题号；不在本模块做整理表单的任何字段填写。
进出靠什么
进：从左侧导航或首页快速收集进入；可带预选学科 ID，没有则用上次所选学科作默认。
出：修框确认后，一个任务产出一道或多道待整理题，进入整理工作台的队列；模块之间靠任务 ID 与新生成的题目 ID 联系。
和其他模块的联系
向共享层供数：左侧导航收集角标等于待修框数加待整理数，其中待整理数来自整理工作台，两边在共享层汇总，本模块不直接读整理模块的页面状态。
与整理工作台的分工：收集只做到框确认与切图为止，学科、文件夹、知识点等一切分类信息都不在收集环节出现。

### 4.3 整理工作台 /organize
管什么
待整理队列：整个工作台是一个固定高度的盒子，队列、整题图、表单都在盒内，滚动只发生在盒内；队列可滚动，排序下拉必须收在队列列宽之内且选项不带括号说明。
队列排序与查找：可按时间正序 / 倒序、学科拼音正序 / 倒序排序；队列上方有搜索框，只搜标题、学科与试卷，不搜题干文字；无结果时显示相应提示文案。
队列行信息：每行显示标题、学科、试卷来源与待补充数量，待补充只统计必填项（学科与文件夹）；当前正在整理的题在队列中有蓝色左边框标识。
翻题规则：上一题 / 下一题跟随当前排序顺序，切换后队列自动滚动定位到当前题；确认整理后自动按当前排序进入下一题。
整题图查看：点击整题图弹出居中大图覆盖层，再点一次、点遮罩或按 Esc 关闭，放大状态下二层框高亮保持可见，支持滚轮缩放。
整理表单（F 分段折叠式）：字段顺序固定为学科、文件夹、试卷、知识点、错误类型、标签、答案、解析、备注；只有学科与文件夹必填，其余选填并计入待补充提示，待补充清单可点击定位到对应字段；备注与答案、解析分开，解析可空。
表单控件口径：文件夹标注为文件夹（归类）、试卷标注为试卷（来源）以免混淆；试卷下拉顶部可直接新增试卷；知识点为学科到章节再到知识点的预置树，展开式多选、不限数量、可显示已选计数；错误类型为固定枚举（审题失误、概念不清、计算错误、方法不会、其他）加自定义，多选、以可移除的标签形式呈现，自定义类型留给该题并在下次可选；标签不限数量，预置易错、常考、需重做可点选，也可新建标签且新建即选中。
编辑安全：切换题目时自动保存、不丢已填内容；整理中可删除题目，须先确认；批量删除不可恢复，确认文案须明示删了就没了。
批量整理：勾选状态在切换题目时保留；批量确认时只拦下缺文件夹的那一道并提示用户，其余照常通过；底部有醒目的蓝色确认按钮，确认后去下一道。
收尾：确认整理时定下首次复习时间为确认后 1 天，复习间隔为 1、3、7、14 天；队列清空时显示小伙伴形象、完成文案与去复习按钮；图片加载失败时以学科图标加题目类型文字兜底显示。
不管什么
不能从整理返回修框：框已在收集中心确认，整理环节不再改框；学科同样不可改，导入时选错由用户自行承担。
不在整理里新建知识点树里没有的知识点，需要新增时去学科管理模块添加。
不做 OCR，只保存收集环节切好的整题图与二层切片图。
进出靠什么
进：从左侧导航进入，或由收集中心修框确认后带着新题目 ID 落入队列；队列内容凭数据层中的待整理状态查询，不依赖收集模块传列表。
出：确认整理后题目状态变为已入库，错题本凭题目 ID 即可见；点去复习按钮去复习模块，不带参数。
和其他模块的联系
向共享层供数：左侧导航整理角标等于待整理数，同时参与收集角标的汇总。
与学科管理的分工：知识点树、文件夹、标签的定义归学科管理维护，整理工作台只负责选用；这是全应用最明确的一条跨模块分工线。
与收集中心的分工：只接收框已确认的题，不回头修改收集结果。

### 4.4 错题本 /wrongbook
管什么
书架状态：进入错题本先看到书架，一页最多显示 6 本书，超过的排到下一页，书架下方有上一页、下一页与页码；现在数学、英语、政治共 3 本，一页放得下，学科变多后自动分页。
每本书的封面：学科色皮本样式，显示计数牌（题数、今日到期、逾期）与开始复习按钮，按钮排在计数牌下方，点击按这一科的题开始复习且不误触打开书。
书架顶部有已归档入口：点开是跨学科的归档列表，每道题可恢复回错题本；书架页本身不放任何搜索与筛选。
打开状态：在本页内由书架切换为打开一本，不跳页；点合上回到书架。打开后显示该科的纸页列表，搜索、筛选、重置、排序都只对当前打开的这一科生效。
书内工具栏：搜索框在列表上方；筛选为折叠式面板，含文件夹、试卷、错误类型、时间、复习状态、标签、仅收藏、仅逾期、已归档等条件，不含学科筛选；重置按钮一键清掉搜索与全部筛选、排序回到时间新到旧、列表回到全部题；排序下拉独立存在。
大卡片（默认视图）：一道题占一行、整行一张卡，整题图占整整一行并占满卡片宽度，图片下方依次是相关信息——题名、学科、错误类型、标签、下次复习时间（含逾期与今天到期标记）与收藏星，不显示文件夹与复习状态。
大卡片滚动容器：大卡片列表是一个固定高度的容器，最多一次性展示两道题，超过两道就在容器内用滚轮滚动、右侧有滚动条，页面本身不被撑长。
紧凑列表：可由工具栏切换，一行一道题，行首有整题图缩略图便于一眼认题，点缩略图弹出放大层看整题图，关闭方式为点关闭、点遮罩或按 Esc；切片加载失败时以学科图标加题目类型文字兜底。
列表分页：每页默认 10 道，可选 10、20、30、40、50；已掌握的题默认不出现，用筛选才可查看。
批量操作（按需出现）：平时列表里没有多选框与批量栏；点批量操作按钮才进入批量模式，出现多选框与批量栏，可批量加标签、加入文件夹、收藏、归档、删除（删除须确认）与清除选择，未勾选时批量按钮禁用；全选当前结果作用于当前筛选结果，筛选、搜索或翻页变化时已选计数随之重算，部分取消时呈半选状态；再点批量操作或退出批量即退出并清掉勾选。
行内操作：收藏星在行内直接切换；点任意一行或一张卡进入题目详情。
不管什么
不在列表里编辑题目，编辑一律去题目详情；列表里看不到答案，答案只在详情与复习翻卡中出现。
不显示试卷来源、不显示复习次数、不显示收集时间、不设序号；收藏不带来任何排序优先，列表与复习顺序都不把收藏题提前。
不提供导出、不提供打印、不提供随机看题（随机在复习模块）、不在本页放学习报告入口；左侧导航错题本不显示数量角标。
左树筛选已整体取消：本页只有顶部折叠筛选一种找题方式，不恢复学科、文件夹、知识点左树。
进出靠什么
进：无参数进入显示书架；带学科 ID 进入则直接打开对应那一本，首页各学科行的错题本入口即用此形态。
出：点行或卡带题目 ID 去题目详情；封面开始复习带学科 ID 去复习；书内开始复习带当前筛选出的题目 ID 集合去复习。
和其他模块的联系
与整理工作台：只通过数据层看已入库题目，整理确认完成的题自动出现，不需要整理模块通知本模块刷新。
与复习：本模块只负责把学科 ID 或题目 ID 集合交出去，复习的排程与翻卡规则全部归复习模块，本模块不预先计算复习顺序之外的任何状态。
与题目详情：本模块是详情的主要入口之一，但详情的编辑结果只写回数据层，本模块重新进入时凭数据层呈现，不缓存详情的编辑状态。

## 五、未确认模块（先划边界，细节待确认）
以下 4 页尚未逐项确认详细设计。本节只锁定边界与进出接口，保证前面 4 页可以先行落地；每页确认完成后，只在本节对应小节补写细节，不改动其他模块的边界。

### 5.1 题目详情 /question/:id
管什么
单道题的完整呈现：整题图与二层切片、题名、学科、文件夹、试卷来源、知识点、错误类型、标签、答案、解析、备注，以及复习状态、已复习次数与下次复习时间。
单道题的编辑：错题本与整理工作台都不承担编辑，改题统一收在本页完成，编辑结果写回数据层。
作为落点页：承接错题本点行、以及未来复习与报告可能带来的跳题需求，凭题目 ID 打开对应题。
不管什么
不做列表、筛选与批量操作，那些归错题本；不执行复习流程，复习的翻卡与自评归复习模块。
不维护知识点树、文件夹与标签的定义，只能选用，定义归学科管理。
进出靠什么
进：必须带题目 ID，无 ID 不打开；来源页不限，错题本为主要来源。
出：返回时回到来源页；本页对其他模块不传状态，编辑结果只经数据层生效。
和其他模块的联系
待确认点：字段排布与分区方式、哪些字段可编辑及编辑控件形态、删除与归档入口是否放在本页、是否需要上一题 / 下一题切换、从本页发起单题复习的入口是否需要。

### 5.2 复习 /review
管什么
按范围取题：今日到期（含逾期）、指定学科、错题本当前筛选结果、单题，均可成为一轮复习的题集。
翻卡自评：先看题、翻卡看答案与解析，再自评会或不会；规则已经定下——两次答对转为已掌握，答错回到复习中，间隔为 1、3、7、14 天，复习中允许跳过。
随机复习：随机看题的入口在本模块，错题本不提供随机。
写回结果：每道题的自评结果、复习次数与下次复习时间写回数据层，供首页计数与错题本列表呈现。
不管什么
不在复习中编辑题目分类信息；不做统计呈现，统计归学习报告；不决定题集之外的题目状态。
进出靠什么
进：可无参数（取今日到期）、带学科 ID（首页卡片与封面开始复习）、或带题目 ID 集合（错题本按筛选开始复习）；首页继续上次可直达未完成的复习进度。
出：一轮结束或中途退出后回到来源页；进度与结果只经数据层保存。
和其他模块的联系
待确认点：翻卡与重铸动画（此前列为招牌元素、暂撤，留到本页讨论时再定）、一轮题量与进度显示方式、会与不会的按钮排布、中途退出的进度保留方式、复习中是否允许跳题目详情。

### 5.3 学习报告 /report
管什么
只读呈现学习统计：面向已入库题目的复习与掌握情况做汇总展示，是全应用唯一做统计呈现的模块。
不管什么
不修改任何题目数据，只读数据层；入口只在左侧导航，错题本内不设报告入口。
进出靠什么
进：从左侧导航进入，不需要参数。
出：如需从统计跳到题目范围，凭学科 ID 去错题本打开对应一本，是否需要此跳转待确认。
和其他模块的联系
待确认点：薄弱点 Top 5 与按试卷分布两项提案尚未确认；统计口径、时间范围与呈现形式均待本页详细设计时定。

### 5.4 学科管理与设置（同一模块，两条路由）
学科管理 /subjects 与设置 /settings 合为一个模块：两者都是低频的维护类页面，不参与收集、整理、复习的业务链，合并后增减时只动一处。
管什么
学科管理：维护学科（初始为数学、英语、政治，均为大学阶段），以及每科的预置知识点树（学科到章节再到知识点，大学层级，如高等数学、大学英语、大学政治相应内容）。
基础字典维护：文件夹（自由建立、可含子文件夹）、标签、自定义错误类型的定义都在此维护，供整理工作台选用。
设置：主题（默认跟随系统、回退亮色，亮 / 深可切换）、字号（标准 / 大，在设置内调整，首页不放字号开关）、缓存与空间清理。
不管什么
不直接编辑任何一道题的内容；不在此处做题目的筛选与批量操作。
设置项不散落到各业务页：主题、字号、缓存清理只在此调整，业务页只服从结果。
进出靠什么
进：从左侧导航进入两个子页，互不带参数；知识点树编辑时带学科 ID 定位到具体学科。
出：维护结果写回数据层，整理工作台与错题本下次打开时凭数据层呈现新定义，不需要本模块逐个通知。
和其他模块的联系
待确认点：两页的详细设计尚未开始；学科删除时其下已有题目的处理方式、知识点树的编辑粒度（增删改的层级限制）、文件夹与标签的合并或重命名规则、设置项的完整清单，均待确认。

## 六、增加一个模块：只动四处
新增功能优先做成新模块。以日后新增一个打印错题本模块为例，需要动的只有以下四处：
1. 新建模块本身：新建一个页面模块，包含它自己的界面、状态与样式，内部实现不引用其他模块的代码。
2. 注册一条路由：在共享层路由表中加一行，把新路径指向新模块。
3. 加入口：在左侧导航加一个入口；如果它只靠别的页面跳转到达，则在那一个来源页加入口，并写清只带 ID 跳转。
4. 按需扩展数据层：确实需要新数据时，只在数据层新增字段或表，不改动现有题目、学科等既有结构。
其他模块不用动的原因：现有模块既不读取新模块的任何状态，新模块也不写它们的内部数据；彼此唯一的交集是数据层与 ID 跳转，而这两处都只做增量，不改既有约定。

## 七、减少一个模块：只动四处
删模块与加模块对称。以假设删除学习报告为例，需要动的只有以下四处；此前删除组卷模块就是按同一方式处理的先例。
1. 删模块本身：删除该页面模块的全部文件。
2. 删路由：在共享层路由表中删掉对应那一行。
3. 删导航入口：在左侧导航去掉它的入口。
4. 清理指向它的跳转：逐个检查其他模块里是否有跳往它的入口，有则一并去掉。这是减模块时唯一需要扫一遍其他模块的地方，且只删入口、不改对方内部逻辑。
数据层里的历史数据不随模块删除：题目、复习记录等数据保留在数据层，日后若恢复该模块可直接再用；确需清理时单独做数据处理，不混在删模块里进行。其他模块不用动的原因与加模块相同：它们从未依赖被删模块的内部状态，入口清干净后即无残留引用。

## 八、修改一个模块：只动它自己
改模块时，先判断改的是内部实现还是对外接口：
只改内部：界面版式、交互流程、内部状态、样式都可任意改，只要路由不变、传入的 ID 不变、写回数据层的字段不变，其他模块零改动。本次错题本由普通列表改为书架加打开书、再改为大卡片一题一行与滚动容器，前后数轮大改都只动了错题本模块内部；唯一的外部小改是首页学科行入口改为带学科 ID 直达打开对应一本，属于入口参数的约定变化，其余页面均未动。
要改接口：若必须改动路由、传入参数或数据层字段，先改共享层，再逐个核对用到该接口的模块。这类改动应单独提出、单独确认，不与内部改版混在一次提交里。
确认进度互不阻塞：未确认的页面不挡已确认页面的修改：题目详情、复习、学习报告、学科管理与设置确认一页、补一页的边界细节，已确认 4 页的边界不因此重开。

## 九、落地检查清单
每个模块交付前逐项自检，任一项不通过即说明边界被越过：
本模块的状态（筛选、勾选、滚动、展开）是否只活在本模块内，没有写给别的模块读？
跳转到别的页面时，是否只带题目 ID、学科 ID 或题目 ID 集合，没有整包传递本页状态？
题目数据是否只经数据层读写，没有在本页私自保存一份长期副本？
知识点树、文件夹、标签的定义是否只在学科管理维护，本页只有选用、没有另建一套？
主题、学科色、字号等视觉变量是否引用共享层，没有在本页重新定义？
删掉本模块时，除路由、导航入口与指向它的跳转外，是否没有任何其他模块需要改代码？
