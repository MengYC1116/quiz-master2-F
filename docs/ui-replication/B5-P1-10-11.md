## SR-P1-10：薄弱 Top5 按题名去重 → 按题 id 计数 ✅

- 现象：`_causeGroups` / `_kpGroups` 用 `titles.contains(q.title)` 去重，
  `count` 是去重后题名数；同名不同题（如都叫“第 1 题/选择题”）只算 1 道，
  Top5 排序与“X 道题”文案都算错。
- 修法：`_WeakGroup` 新增 `questionIds: Set<String>`，`count` 改为
  `questionIds.length`；两处分组改为
  `if (g.questionIds.add(q.id)) g.titles.add(q.title);`——题 id 去重计数，
  `titles` 只作展示行拼接（同名题在详情行里各出现一次）。
- 回归测试：`SR-P1-10：同名不同题各算 1 道，原因组与知识点组都计 2 道`——
  两道同名“选择题”（不同 id，同错因、同知识点）→ 原因组“2 道题”、
  知识点组“还没解决 2 道”、分布“数学 · 2 道错题”。

## SR-P1-11：弱点 Top5 与学科分布排除未整理题、已归档题 ✅

- 现象：`_questionsInRange` 只按 `createdAt` 过滤，弱点分组与学科分布
  把未整理题（还在整理工作台排队）与已归档题也算进去，与错题本列表
  默认口径不一致（报告分布数会大于错题本题数；点弱点行进错题本后
  找不到这些题）。
- 修法：`_questionsInRange` 增加 `q.isOrganized && !q.isArchived` 过滤，
  与错题本 `_filteredAll` / `_folderCount` 的收录口径一致；三个核心数
  （按错因记录计，不按题目计）不受影响，未动。页头口径注释同步更新，
  写明该口径及两项编号。
- 回归测试：`SR-P1-11：未整理题与已归档题不进弱点 Top5 与学科分布`——
  已整理题 + 未整理题 + 已归档题（同错因、同知识点）→ 原因组“1 道题”、
  知识点组“还没解决 1 道”、分布“数学 · 1 道错题”，且页面上找不到
  “未整理题”“已归档题”。
