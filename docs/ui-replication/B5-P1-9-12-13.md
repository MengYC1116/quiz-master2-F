## SR-P1-9：复习“上次自查”显示最早一次，不是最近一次

- 位置：`lib/modules/review/review_page.dart` `_buildStepCause`（原 `:1482`）
- 根因：`reviewHistory()` 的 SQL 是 `reviewed_at DESC`（新→旧，见 `lib/data/db_questions.dart:140-144`），代码却取 `history.last`，即最旧一条。
- 修复：`history.last` → `history.first`（DESC 下首条即最新）。与同页 `_buildStepRemedy` 取 `remedyHistory.first` 的用法一致。
- 回归测试（`test/review_page_test.dart`，B5 组）：同一题两条自查记录（新“已解决” 2026-11-09、旧“未解决” 2026-11-01，按 DESC 顺序喂 fake），第 ① 步显示 `2026-11-09 · 「已解决」`，不出现旧日期。

## SR-P1-13：跳过一题的最后一个错因，把上一个已写完补救的错因重新呈现

- 位置：`lib/modules/review/review_page.dart` `_skipCurrent`（原 `:571-603`）
- 根因：`removeAt(_ci)` 后 `_ci >= length` 时把 `_ci` 钳回 `length - 1` 并回到 `recall`，于是上一个已写完补救的错因被重新呈现（内容已存库未丢，但须多点一次“下一步”）。
- 修复：按 SELF-REVIEW.md 建议，复用 `_nextFromRemedy` 的收尾判断——跳过的是块内最后一个错因时直接进 `_Phase.redo`，只有块中部跳过才停在当前 `_ci`（下一个未走完的错因顶上来）。`_ci` 仍钳回块内末位，因为 `_buildSession` 无条件取 `_currentCause` 查记录，`_ci` 越界会抛 `RangeError`；`_buildCauseMeta`（`本题错因 n / m`）只在 ①② 步渲染，redo 步不受影响。
- 回归测试（`test/review_page_test.dart`，B5 组）：双错因题，前一错因走完 ①② 步、在第二错因 ① 步点“跳过该题”，应出现重做步独有文案“答案遮着：自己把这道题重做一遍，再点开答案对照”，且 `本题错因 1 / 2` 与 `下一步：写补救` 均消失；随后“看答案 → 下一步：自查”能正常进自查步（下一题进队尾重排块）。
- 测试写法注意：步骤指示条四颗 pill（① 看错因 / ② 写补救 / ③ 重做 / ④ 自查）常驻，不能用 pill 文案断言所在步骤——初版测试因此误断言，已改用重做步独有文案断言。

## SR-P1-12：排序与每页条数每次 `_load()` 都被重置回设置默认值

- 位置：`lib/modules/wrongbook/wrongbook_page.dart` `_load`（原 `:171`、`:179`）、`lib/modules/review/review_page.dart` `_load`（原 `:283`）
- 根因：`_viewMode` 已在 B2 用 `_viewModeInitialized` 标志修掉同类问题，但 `_sort` / `_pageSize`（错题本）与 `_pageSize`（复习）仍在每次 `_load()` 无条件覆盖。复习页字段注释本就写着“只在打开时从设置默认值读一次初值”，代码与注释直接矛盾。
- 修复：与 `_viewModeInitialized` 同款，各加首次标志，只在首次 `_load()` 取设置默认值，之后保留页内选择：
  - 错题本：新增 `_sortInitialized` / `_pageSizeInitialized`；`_defaultSort` 仍每次更新（“重置”按钮仍回到设置默认值，不动 SR-P2-58 的口径）。
  - 复习：新增 `_pageSizeInitialized`；同步修正下拉 `onChanged` 注释“初值仍在 _load 里从设置默认值读”→“初值只在首次 _load 里从设置默认值读”，使注释与代码一致。
  - 新进页面（新 State 实例）时标志复位，仍读设置默认值。
- 回归测试（5 项中 3 项属本项）：
  - 错题本（`test/wrongbook_page_test.dart`，B5 组）：排序改成“时间 旧 → 新”后进详情返回，仍是旧→新；12 道题、每页改成 20 后进详情返回，仍是“共 12 道 · 第 1 / 1 页”。
  - 复习（`test/review_page_test.dart`，B5 组）：页数默认值 2（共 3 条 · 第 1 / 2 页），改成 20 后进会话再暂停回列表（`_pauseSession` 末尾调 `_load()`），仍是“共 3 条 · 第 1 / 1 页”，且设置默认值未被改写（`repo.settingsValue.pageSize` 仍为 2）。
