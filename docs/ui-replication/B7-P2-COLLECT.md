## SR3-10 — 详情页打开时自愈“库新图旧”（选修法 a）

- 修法（选 a，不选 b/c）：`lib/modules/detail/question_detail_page.dart` 新增 `_healSliceIfNeeded`，在 `_load()` 之后不 await 调用（自愈是后台修复，不挡页面渲染）：
  - 切片文件存在且 `pngDimensions` 读出的实际尺寸与库里 `sliceWidth`/`sliceHeight` 一致 → 记键，不再重复读盘；
  - 不一致（或切片已不是合法 PNG）→ 按当前第一个 1 层框重裁，临时文件 + 同目录 rename 原子替换，清 `FileImage` 缓存；重裁尺寸与库里记的不一样时再 `repo.save` 改库里尺寸；成功后调一次 `_load()` 刷新；
  - 切片文件不存在时不处理（仍走原有的图加载失败占位）；页图缺失/损坏、框缺失时静默放弃，不弹提示；
  - 任何一步失败只 `debugPrint`，不打扰用户、不抛到界面；失败不记键，下次 `_load` 再试。去重键是 `题 id|切片路径|库里尺寸`，进行中标志防并发重复跑。
- 支撑：`lib/services/page_image_pipeline.dart` 新增 `pngDimensions(Uint8List)`——只解析 PNG IHDR 宽/高，不解码整图；损坏/截断/非 PNG 返回 null（调用方按“尺寸不符”处理）。
- 注释：`_reworkBoxes` 的临时文件注释补一句——事务提交后、rename 前被杀是另一个崩溃窗口，孤儿扫描扫不到它（旧图仍被 `slice_path` 引用），由打开详情页时的自愈修复。
- 用例（`test/detail_page_test.dart`，新组 SR3-10/SR3-11，1 项）：`SR3-10：打开详情页时切片实际尺寸与库里不符，按当前框重裁自愈`——旧切片用 560×700 页图字节、库里记 200×100；`runAsync` 推进后断言切片文件已重裁为 492×280（`left=(0.06×560).round()=34、right=(0.94×560).round()=526`），`repo.saved` 里 q1 的 `sliceWidth/sliceHeight` 同步为 492/280，`takeException()` 为空。
- 既有用例调整（修法带来的基线变化，不是回归）：`SR2-3：事务失败时旧切片字节完好` 的夹具（库里记 200×100、磁盘是 560×700 旧图）正是自愈要修的状态，打开页时自愈会先重裁——测试里先在 `runAsync` 内把自愈跑完，再以自愈后的切片为基线断言“事务失败不碰切片”，并把自愈调的那一次 `repo.save` 清掉（`repo.saved.clear()`），后面“事务失败不存题”的断言才只量本次重框。断言意图不变（失败不碰当时的切片），只改基线，注释已写明。

## SR3-12 — 独立题内框挂接：面积平局判据 + 0.25 距离上限

- 修法：`lib/modules/collect/collect_page.dart` 的 `_nearestLayer1Box` 改三态返回 `({QuestionBox? box, bool ambiguous})`：
  - 距离上限：中心离最近的题都超过页宽/高的 0.25（归一化坐标下页宽/高为 1）→ 不挂（`box: null, ambiguous: false`）；
  - 平局：距离相同的候选里取与内框相交面积最大者（新增 `_intersectionArea`）；仍平局 → 判歧义（`box: null, ambiguous: true`），不静默取列表先到者；
  - `_confirmSplit` 里歧义/过远分别计数（跨页累计），成功后随成功提示一起报：“有 N 个题内框同时落在两道题里，请手动指定归属” / “有 N 个题内框离所有题太远，未归属，请手动处理”。未归属的内框本次确认不入库（留在 `standaloneInner` 的语义：不进 `boxesByQuestionId`）。
- 用例（`test/collect_page_test.dart`，SR2-4 组后新组，3 项）：
  - `中心在两道题正中间、距离与相交面积都平局：不挂，提示手动指定归属`——b1 到 0.25、b2 从 0.75 起，stem 中心 (0.30, 0.50)，离两框都是 0.25、相交面积同为 0；断言不挂、提示出现。坐标全取二进制精确值（0.25/0.5/0.75/0.4375/0.125），避免十进制小数的浮点差打破平局。
  - `中心离所有题都超过页宽/高的 0.25：不挂，提示手动处理`——两道小题框在页顶、stem 在页底（最近距离约 0.6）；断言不挂、提示出现。
  - `中心落在两道题里但相交面积不等：挂到相交面积大的一道`——两框共用 y=0.5 的边（y 不重叠，编辑器放行确认），x 向右沿不对称（b1 右沿 0.58、b2 左沿 0.46），stem 中心 (0.50, 0.50)，与 b1 相交 0.28×0.1、与 b2 相交 0.24×0.1；断言挂到 b1、两条提示都不出现。
- 可达性说明（写在用例注释里）：中心落在框内的内框在打开编辑器时就被 `groupInners` 按中心点收归首道框、到不了 `standaloneInner`，且编辑器会拦下重叠的 1 层框确认，所以“真重叠 + 面积平局”经 UI 造不出来；歧义分支用“等距间隙”构造，走的是同一条平局判据（距离相等 + 相交面积相等 → 歧义）。第一版用例用“公共边”构造时被 `groupInners` 预分组，断言失败，已按此修正。
