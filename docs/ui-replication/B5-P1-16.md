# B5-P1-16：YOLO 模型首次加载失败后永久锁死

- 自审项：SR-P1-16（`docs/ui-replication/SELF-REVIEW.md`）
- 状态：已修复并验证通过，未提交、未推送

## 问题

`lib/services/yolo_onnx_service.dart` 的 `_ensureLoaded` 在尝试加载前就把
`static bool _loadAttempted` 置真，失败后该标志恒为真，之后每次 `detectPage`
都直接返回“自动检测不可用，请手动框选”，不再尝试加载。Meng 在应用运行中
把模型文件放进 `assets/models/question/` 后，必须重启应用才生效。

## 修法

加载失败不锁死，成功后仍缓存复用：

- `_ensureLoaded` 改为：已加载成功（`_loadOk`）直接返回 true；否则重新尝试
  加载，失败不留任何“已尝试”标记，下次检测再次尝试。
- 旧的 `_loadAttempted` 字段已删除：它与 `_loadOk` 完全等价（只写不读，
  `flutter analyze` 报 `unused_field`），失败不锁死的语义现在由“失败时
  `_loadOk` 保持 false + 不保留在途标记”直接表达；`resetLoadStateForTest`
  同步更新（不再碰该字段）。
- 新增 `_loadFuture` 在途 guard：并发检测共用一次加载，避免 38MB 模型被
  重复加载；加载失败后清空，下次检测重新尝试。加载逻辑拆为
  `_ensureLoaded`（缓存/在途/重试）+ `_loadOnce`（一次真实加载）。
- 失败时 `_questionSession` 置空，不留半截会话。

## 不反复打扰用户的说明

核查了全部 `detectPage` 调用方（`collect_page.dart:371`、
`box_editor.dart:467/516/555`）：自动检测路径失败时是静默的（只保留
fallback 提示、不落占位框），仅用户主动点“恢复自动框”时才按点击次数
弹一次 SnackBar。重试只是在每次检测时多走一次廉价的 asset 加载失败
（模型缺失时 `rootBundle.load` 快速抛错），不新增任何弹窗面。

- `lib/services/yolo_onnx_service.dart`：`_ensureLoaded` 重写为缓存 + 在途
  共用 + 失败重试；新增 `_loadOnce`、`_loadFuture`；删除 `_loadAttempted`；
  `resetLoadStateForTest` 同步更新。

## 回归测试

新测试一次覆盖三点，同一进程内、无需重启：

1. 用不存在的模型路径检测一次 → `usedFallback` 为真、提示手动框选、
   `hasRealModel` 为假；
2. 换回真实模型路径再次检测 → `usedFallback` 为假、`lastDetectStats`
   非空（旧实现此处会一直返回 fallback）；
3. 成功后缓存复用：再用不存在的模型路径的实例检测 → 仍走已加载的
   会话，`usedFallback` 为假、`hasRealModel` 为真（证明成功后不重复加载）。

测试用临时合成图 + 临时目录，`finally` 里删除临时目录并
`resetLoadStateForTest()`，不碰真实演示库。
