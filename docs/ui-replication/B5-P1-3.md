# B5 第二阶段 P1-3：`deleteExam` 包事务，删无意义的 `name=''`

- 日期：2026-11-14
- 来源：`SELF-REVIEW.md` SR-P1-3
- 分支：`ui-replication`（未提交、未推）

## 问题

`AppDatabaseCatalog.deleteExam`（`lib/data/db_catalog.dart:436-447`）三步顺序写、无事务：

1. `update exams set name=''` —— 死步骤，下一秒行就被删掉，疑似复制粘贴残留；
2. `delete exams`；
3. `update questions set exam_id=null`。

中间失败/崩溃会留下半截状态：试卷已删但题还指着不存在的 `exam_id`（悬空引用；错题本按试卷筛题时这批题丢过滤）；或试卷还在但名字被清空成 `''`（学科管理里出现无名试卷）。

## 修法

- 删掉 `name=''` 那行。
- 剩余两步包进 `db.transaction`，仿同文件 `deleteTagFromImpl` / `deleteKnowledgePointFromImpl` / `deleteChapterFromImpl` 的事务版写法。
- 顺手补了可单测版 `deleteExamFromImpl`（顶层函数）+ `AppDatabase.deleteExamFrom` 静态转发，`deleteExam` 改走它。
- 调用方 `repository.dart:287`、`subjects_page.dart:285` 不用动，未动。

## 改动文件

- `lib/data/db_catalog.dart`：新增 `deleteExamFromImpl`（事务：删试卷行 + 题上 `exam_id` 置空）；`deleteExam` 改走 `AppDatabase.deleteExamFrom`，删 `name=''` 步骤。
- `lib/data/database.dart`：新增静态转发 `AppDatabase.deleteExamFrom`。
- `test/b5_p1_3_delete_exam_test.dart`（新增，3 项，内存库，不碰真实库）：
  1. 删试卷：试卷行消失，挂了该试卷的题 `exam_id` 置空，其余试卷/题不动；
  2. 中途失败回滚：触发器让第二步（题上置空）必失败，试卷行与名字完整保留、题仍指着它；
  3. 删不存在的试卷：不抛错，不动任何题。
